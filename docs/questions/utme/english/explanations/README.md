# Worked explanations for UTME Use of English

One file per skill. Each entry is keyed on the question version's id and carries the steps the
coach writes on the board and the hint offered after a first wrong answer.

The rules these are written to:

* **Say what the word means before saying which option is right.** "The key is C" teaches
  nothing; "*garrulous* means talkative, so its opposite is *reticent*" teaches the word.
* **Name the trap when there is one.** Most of these questions have one option that is
  tempting for a reason, and saying why it is wrong is usually worth more than saying why the
  key is right.
* **Do not pad.** Two steps is normal, three is the most any of these needs. A student who has
  just got a question wrong is not reading an essay.
* **Where the source is mangled, say so rather than explaining around it.** The extraction
  moved some italicised words to the end of their sentence, and a few questions are missing
  words. The explanation should read as though written by someone who noticed.

`solution_source` is set to `expert_verified` when these load, because a person wrote them
against the question. That is a claim about this prose, not about the answer key.
