# ADR-0002 · Single repository, npm and uv workspaces

- **Status:** Accepted
- **Date:** 2026-09-17

## Context

The product needs a Python API, a Python engine, a TypeScript web client, a small
TypeScript engine slice that must stay in step with the Python one (ADR-0005),
shared test fixtures, SQL migrations and analysis notebooks.

The engine and its TypeScript mirror must be changed and tested together, or they
drift. Fixtures generated by the Python engine are consumed by TypeScript tests.

## Decision

One repository, two package managers, each owning its own language:

```
apps/api            FastAPI service
apps/web            React client
packages/engine     Python engine (pure, versioned)
packages/engine-ts  TypeScript engine slice for offline use
packages/fixtures   Generated parity and golden vectors (JSON)
packages/api-client Generated TypeScript API client
database/           migrations, seeds, loader, tests
analysis/           notebooks and calibration scripts
docs/               product spec, roadmap, ADRs
```

- **Python:** a uv workspace declared in the root `pyproject.toml`, with
  `apps/api` and `packages/engine` as members. One lock file, one virtual
  environment.
- **JavaScript:** npm workspaces declared in the root `package.json`. npm is
  already installed; pnpm would be marginally faster but adds a prerequisite.
- **Task running:** a `Makefile`. `make` is present on every developer machine;
  `just` would need installing.

## Consequences

- A single pull request can change the engine, its mirror and the fixtures together,
  and CI proves they still agree.
- Two toolchains in one repository. The `Makefile` hides that behind one set of
  commands (`make setup`, `make test`).
- CI runs two jobs (Python, JavaScript) plus a parity job that needs both.

## Alternatives considered

- **Separate repositories per service.** Cross-repository pull requests for a single
  logical change; parity drift becomes likely.
- **Turborepo or Nx.** Build orchestration this project doesn't need with one web app.
- **pnpm.** Better workspace ergonomics, but an extra tool to install for a benefit
  that doesn't show at this size.
